Starting FalconBroom…

Deleting app data during uninstall removes local files and any remaining keys. Keep app data unless you intend to delete it.

Recommended: start a separate empty profile. The existing profile stays in place. Close all older FalconBroom versions and workers first.

Alternatively, restore a previously exported recovery file for this profile. An unreadable key file is kept as a backup. A recovery file must have been exported before the key was lost.

To return to another preserved profile, select it below. Restart FalconBroom after changing profiles.
